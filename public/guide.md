## 一、导入照片

### 1.1 上传方式
- 点击页面中央的 **上传图片** 区域，选择本地图片文件（支持 JPG / PNG / WEBP）
- 也可以直接将图片**拖拽**到上传区域

### 1.2 自动去背景
- 上传后可开启 **"自动去除背景"** 功能，适合主体明显的卡通图案
- 去背景后主体会保留，背景变为透明
- 如果效果不理想，可关闭此功能使用原图

### 1.3 图片建议
| 适合 | 不适合 |
|------|--------|
| 线条清晰的卡通/插画 | 背景复杂的风景照 |
| 颜色块面分明的图案 | 渐变色过多的摄影照片 |
| 正面朝向的人物/动物 | 极小分辨率图片（建议 200px 以上）|

## 二、图纸规格设置

### 2.1 格子数量（分辨率）
- 通过页面上的 **"格子数"** 滑块或输入框控制图纸横向格子数
- 数值越大，细节越丰富，所需豆豆数量越多
- 推荐范围：

| 用途 | 建议格子数 |
|------|-----------|
| 小挂件 / 发夹 | 20–40 格 |
| 普通装饰摆件 | 40–80 格 |
| 大型作品 | 80–150 格 |

### 2.2 选择豆豆品牌/色系
- 在 **"色号体系"** 下拉框中选择品牌：
  - **MARD**（玛德）
  - **咪小窝**
  - 其他主流品牌
- 切换品牌后色号会自动重新映射为对应品牌的颜色

### 2.3 厂家切换
- 生成图纸后，可在结果区域找到 **"切换厂家"** 按钮
- 一键将所有色块替换为另一品牌的等价色号，无需重新上传

### 2.4 颜色相似度调节
- 通过 **"相似度"** 滑块调节颜色归并严格程度
- 数值较低：颜色更丰富细腻
- 数值较高：颜色更少，更易拼制

### 2.5 排除特定颜色
- 在色号统计面板中，点击某色号的 **"排除"** 按钮，可将该颜色从调色板中移除
- 适合手头没有某种颜色豆豆时使用

## 三、手动编辑模式

生成图纸后，点击 **"手动编辑"** 按钮进入编辑模式，右上角会弹出悬浮工具栏。

### 3.1 工具栏概览

```
┌─────────────┐
│  工具选择区  │  ← 所有绘图工具
├─────────────┤
│  对称操作区  │  ← 仅框选工具激活时显示
├─────────────┤
│   🎨 调色盘  │
│   🔍 放大镜  │
│   ↩ 撤销    │
│   ↪ 重做    │
│   ✕ 退出    │
└─────────────┘
```

### 3.2 绘图工具详解

| 图标 | 工具名 | 使用方法 |
|------|--------|----------|
| ✏️ 画笔 | 画笔 | 单击或拖拽，在格子上涂色；可选 1/3/5 格笔刷大小 |
| 💉 取色 | 取色器 | 点击任意格子，提取该格颜色作为当前颜色；取完自动切回画笔 |
| ╱ 线 | 直线 | 拖拽起点到终点，绘制一条直线 |
| □ 矩形轮廓 | 矩形边框 | 拖拽绘制空心矩形 |
| ■ 矩形填充 | 矩形实心 | 拖拽绘制填满颜色的矩形 |
| ○ 椭圆轮廓 | 椭圆边框 | 拖拽绘制空心椭圆/圆 |
| ● 椭圆填充 | 椭圆实心 | 拖拽绘制填满颜色的椭圆 |
| ⬚ 选区 | 框选工具 | 拖拽选定矩形区域，用于对称操作（见下方）|

> **拖拽预览**：除画笔外，其他工具拖拽时会显示**蓝色半透明预览**，松手后才真正上色。

### 3.3 框选对称功能

这是专为卡通图案设计的功能，适合**眼睛、脸颊、衣服等左右/上下对称**的区域。

**操作步骤：**

1. 选择 **⬚ 框选工具**
2. 在画布上**拖拽**圈出需要对称的区域（如左眼所在的范围）
3. 选区会显示蓝色虚线边框 + 红色十字辅助线（显示对称轴）
4. 工具栏出现 **对称操作面板**，选择方向：

| 按钮 | 效果 |
|------|------|
| **左→右** | 将选区左半复制镜像到右半（常用于做右眼/右脸颊）|
| **右→左** | 将选区右半复制镜像到左半 |
| **上→下** | 将选区上半复制镜像到下半 |
| **下→上** | 将选区下半复制镜像到上半 |

5. 点击对称按钮后立即生效，可按 **Ctrl+Z 撤销**
6. 点击「✕ 取消选区」清除框选，继续用其他工具编辑

### 3.4 调色盘
- 点击 🎨 按钮打开 / 关闭悬浮调色盘
- 从调色盘中点选颜色后，用画笔工具在格子上涂色
- 支持 **橡皮擦** 模式，可擦除格子颜色

### 3.5 放大镜
- 点击 🔍 按钮激活放大镜
- 在图纸上框选区域后，放大显示该区域，方便精细编辑细节格子

### 3.6 撤销与重做
- **撤销**：点击 ↩ 按钮，或按 `Ctrl + Z`（最多 30 步）
- **重做**：点击 ↪ 按钮，或按 `Ctrl + Y`
- 退出编辑模式时，撤销/重做历史自动清空

### 3.7 退出编辑模式
- 点击右上角 **✕ 退出** 按钮
- 编辑结果会保留在图纸中，可继续下载

## 五、专心拼豆模式

专心拼豆模式是一个 **拼豆过程辅助工具**，帮助你在拼豆时逐格追踪进度。

### 5.1 进入方式
- 图纸生成后，点击下载弹窗中的 **"进入专心拼豆模式"**，或直接访问 `/focus` 页面

### 5.2 界面说明

```
┌────────────────────────────────────────┐
│         图豆儿拼豆图纸（显示区）          │
│                                        │
│  [已完成格显示为深色]                    │
│  [未完成格显示原色]                      │
│                                        │
└────────────────────────────────────────┘
┌──────── 底部工具栏 ────────────────────┐
│ [进度 ▓▓▓▓░░░░ 45%] [预计剩余 2h30m] │
│ [轮廓模式] [↩ 撤销] [⊕ 设置原点]      │
└────────────────────────────────────────┘
```

### 5.3 标记格子
- 点击格子将其标记为**已完成**（颜色加深）
- 再次点击取消标记
- 已完成的格子会从进度统计中实时更新

### 5.4 拼豆模式切换

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **色块模式**（默认）| 点击标记整个同色连通区域 | 拼同一颜色的一整片区域 |
| **轮廓模式** | 点击只标记该色块的外圈格子 | 先拼边框再填内部时使用 |

- 点击底部工具栏的 **"轮廓/色块"** 按钮切换

### 5.5 坐标系统
- 点击底部的 **"⊕ 设置原点"** 按钮进入原点设置状态
- 点击图纸上任意格子作为 **坐标原点（0, 0）**
- 之后鼠标悬停在任意格子时，会显示相对于原点的 **(X, Y) 坐标**，方便按图找位置

### 5.6 进度条与预估时间
- 底部进度条实时显示**完成百分比**
- 根据你的拼豆速度自动计算**预计剩余时间**
- 进度会自动保存到浏览器本地缓存，关闭页面后再次进入可继续

### 5.7 撤销功能
- 点击底部 **↩ 撤销** 按钮，或按 `Ctrl + Z`
- 取消最后一次点击操作，支持多步撤销

### 5.8 注意事项
- 专心拼豆模式的进度**只保存在当前浏览器**，清除浏览器数据会丢失进度
- 建议在同一设备、同一浏览器中持续使用
- 切换图纸（重新上传）后之前的进度会清空

## 常见问题

**Q：图纸颜色不够准确怎么办？**  
A：可以降低「相似度」数值让颜色更丰富，或进入手动编辑模式逐格修正。

**Q：密钥输入了提示无效？**  
A：请检查是否完整复制（含横杠），密钥区分大小写，建议直接粘贴。

**Q：换了电脑密钥还能用吗？**  
A：密钥与次数绑定，不与设备绑定，换设备重新输入密钥即可（次数共用）。

**Q：专心拼豆进度丢失了？**  
A：可能是清除了浏览器缓存，目前进度保存在本地 `localStorage` 中，建议不要清除。

**Q：能导出成 CSV 文件吗？**  
A：支持！在下载弹窗中选择导出格式，可保存为 CSV 备用。
